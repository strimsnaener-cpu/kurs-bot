# NeuralDesk — как продолжить работу

Это полный проект платформы (этапы 1–7 из 9) и всё, что нужно, чтобы продолжить с того же места.

## Что в папке
- `app/` — сама платформа: сервер, страницы, тесты
- `CLAUDE.md` — полный контекст проекта для ИИ-помощника (Claude Code читает его сам, другим можно скинуть файлом)
- `start.ps1` — первый запуск одной командой
- `docs/ARCHITECTURE.md` — исходный план (этап 1)
- `prisma/schema.prisma` — схема базы для будущего перехода на PostgreSQL

## Запуск в PowerShell
1. Установи **Node.js LTS (22.13 или новее)** с https://nodejs.org. Проверка: `node -v`
2. Открой PowerShell в этой папке и выполни:
   ```
   powershell -ExecutionPolicy Bypass -File .\start.ps1
   ```
   Скрипт сам создаст `app\.env` с ключом шифрования, прогонит тесты и запустит сайт на http://localhost:3000
3. Зарегистрируйся на сайте, потом в **другом** окне PowerShell:
   ```
   cd app
   npm run make-admin -- твой@email.com
   ```
   Войди заново и включи 2FA в Dashboard. После этого открывается админка: http://localhost:3000/admin.html

Письма (подтверждение почты, сброс пароля, ответы поддержки) пока **не отправляются** — их можно посмотреть тут: http://localhost:3000/api/dev/outbox

Файл `app\.env` и папку `app\data` никому не отправляй и не выкладывай: там ключ шифрования и база.

## Проверка, что всё работает
```
cd app
npm test                     # 41 группа тестов сервера
npm i -D playwright
npx playwright install chromium
npm run test:browser         # 6 сценариев в настоящем браузере
```

## Чтобы агенты отвечали по-настоящему
- **Telegram:** в `app\.env` впиши `OPENAI_API_KEY` и `OPENAI_MODEL` (модель, которая есть в твоём аккаунте OpenAI). Без ключа агенты работают в режиме «только FAQ». На ПК `PUBLIC_URL` оставь пустым — сервер сам опрашивает Telegram.
- **Instagram:** нужно приложение Meta, публичный HTTPS-адрес и тестовый аккаунт. Пошагово — в `app\README.md`, раздел Instagram. Подавать в Meta App Review лучше заранее: это занимает недели.

## Продолжить с ИИ в PowerShell
Если используешь Claude Code: открой PowerShell в этой папке, запусти `claude` и напиши, например:
> Прочитай CLAUDE.md и продолжи с этапа 8 (оплата). Платёжка: WayForPay.

Он сам подхватит весь контекст из `CLAUDE.md`. Для другого помощника — просто отправь ему этот файл первым сообщением.

## Что дальше
1. **Этап 8 — оплата.** Сейчас заказы подтверждаются вручную кнопкой «Mark paid» в админке. Нужно твоё решение, какая платёжка:
   - **WayForPay** или **LiqPay** — карты в гривнах для Украины

   Можно сделать одну украинскую и одну международную.
2. **Этап 9 — запуск.** Настоящая отправка писем (сервис вроде Resend), хостинг с HTTPS и доменом, резервные копии базы, страницы «Политика конфиденциальности» и «Условия», проверка Meta, мониторинг.
3. **По желанию:** перенос на Next.js + PostgreSQL. На твоём ПК пакеты ставятся, так что теперь это возможно. Сейчас всё работает и без этого.

## Что заменить своим
- Цены (все временные) — меняются в админке
- Название «NeuralDesk» — если хочешь своё
- Твоя история и фото на странице About

## Ограничения сейчас
- Агенты понимают только текст: фото и голосовые пока игнорируются
- В базу знаний — только текст и файлы .txt/.md (PDF/Word — вставлять текстом)
- Реальные Telegram, Instagram и OpenAI ещё ни разу не проверялись вживую — проверялись на точных имитациях их API. Первый живой запуск — на твоём ПК.
